# pdf-ua-fixer

A command-line tool that post-processes a PDF to fix PDF/UA-1 accessibility
errors reported by [PAC (PDF Accessibility Checker)](https://pac.pdf-accessibility.org).

Designed for PDFs generated by **pdflatex + tagpdf** (TeX Live 2024/2025),
but the fixes apply to any PDF with the same underlying issues.

---

## Quick start

```bash
# 1. Clone and install dependencies
git clone https://github.com/your-username/pdf-ua-fixer.git
cd pdf-ua-fixer
pip install -r requirements.txt

# 2. Fix your PDF (saves to thesis_fixed.pdf next to the original)
python fix_pdf.py path/to/thesis.pdf

# 3. Verify the fixes
python verify_pdf.py path/to/thesis_fixed.pdf
```

---

## Installation

**Requirements:** Python 3.9 or later.

```bash
pip install -r requirements.txt
```

This installs `pikepdf` (≥ 10.0) and `pypdf` (≥ 4.0).

No LaTeX installation is required — the tool works directly on the PDF.

---

## Usage

### Fix a PDF

```bash
python fix_pdf.py <input.pdf> [options]
```

| Option | Description |
|--------|-------------|
| *(no option)* | Save fixed PDF as `<input>_fixed.pdf` in the same folder |
| `--output out.pdf` | Save to a specific path |
| `--inplace` | Overwrite the input file directly |

**Examples:**

```bash
# Default: saves thesis_fixed.pdf next to thesis.pdf
python fix_pdf.py thesis.pdf

# Save to a different name
python fix_pdf.py thesis.pdf --output thesis_ua.pdf

# Overwrite in place (useful after every LaTeX rebuild)
python fix_pdf.py thesis.pdf --inplace
```

### Verify a PDF

Runs automated checks and prints PASS/FAIL for each issue:

```bash
python verify_pdf.py thesis_fixed.pdf
```

Expected output on a fully fixed PDF:

```
PDF/UA identifier  pdfuaid:part = '1'  [PASS]
TH /Scope          61 with scope, 0 missing  (tables: 10)  [PASS]
Artifact content   no tagged content inside artifacts  [PASS]
──────────────────────────────────────────────────
All checks PASSED
```

## What it fixes

### Fix 1 — "Second path object not tagged"

**Cause:** LaTeX packages like `booktabs` (`\toprule`, `\midrule`, `\bottomrule`,
`\cmidrule`) and some drawing commands emit raw PDF path operations completely
outside any marked-content block. PAC flags these as untagged.

**Fix:** Scans every page content stream and wraps each untagged path sequence
in `/Artifact BMC … EMC`, marking it as decorative.

---

### Fix 2 — "Table header cells has no associated subcells"

**Cause:** `tagpdf` stores the TH column scope via ClassMap only (`/C /TH-col`).
PAC does not resolve ClassMap references, so the scope is invisible to it.

**Fix:** Adds a direct `/A << /O /Table /Scope /Column >>` attribute to every
TH structure element in the document structure tree, alongside the existing
ClassMap entry.

---

### Fix 3 — "Tagged content present inside an artifact"

**Cause:** `tcolorbox` (and similar box environments) emits a single
`/Artifact BMC … EMC` wrapper that encloses both the box background/border
paths and the tagged text inside the box. PDF/UA-1 forbids tagged content
nested inside an artifact.

**Fix:** Finds every `/Artifact` block containing inner `BDC`/`BMC` markers,
removes the outer artifact wrapper, and re-wraps only the pure path-drawing
operations as individual artifact blocks. Text content is left properly tagged.

---

### Fix 4 — "PDF/UA identifier missing"

**Cause:** The XMP metadata packet does not declare `pdfuaid:part = 1`.

**Fix:** Writes `pdfuaid:part = 1` under the
`xmlns:pdfuaid="http://www.aiim.org/pdfua/ns/id/"` namespace in the PDF's
XMP metadata.

## Typical workflow

If you build your PDF from LaTeX, run this tool once after each build:

```bash
pdflatex thesis.tex   # (your usual build command)
python fix_pdf.py thesis.pdf --inplace
```

The fixes are idempotent — running the tool a second time on an already-fixed
PDF makes no changes.

---

## Notes

- **Non-destructive:** fixes only add/adjust PDF accessibility markup.
  Visible content, fonts, and layout are not changed.
- **Tested on:** pdflatex + tagpdf (TeX Live 2025), 250+ page documents.
- **Not tested on:** XeLaTeX, LuaLaTeX, or non-LaTeX PDF generators.
  The fixes are general enough to work, but have not been verified.

├── requirements.txt

    ├── utils.py            shared helpers (content-stream parsing, serialization)
