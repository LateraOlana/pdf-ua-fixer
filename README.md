# pdf-ua-fixer

A command-line tool that checks PDFs for **WCAG 2.1 Level AA** accessibility
compliance (required by ADA Title II) and automatically fixes common issues.

Designed for PDFs generated by **pdflatex + tagpdf** (TeX Live 2024/2025),
but the checks and fixes apply to any PDF.

---

## Quick start

```bash
# 1. Clone and install dependencies
git clone https://github.com/latera_ihme/pdf-ua-fixer.git
cd pdf-ua-fixer
pip install -r requirements.txt

# 2. Check a PDF — produces a full accessibility report
python check_pdf.py your_document.pdf

# 3. Check AND apply all automatic fixes
python check_pdf.py your_document.pdf --fix
```

---

## Installation

**Requirements:** Python 3.9 or later.

```bash
pip install -r requirements.txt
```

This installs `pikepdf` (≥ 10.0), `pypdf` (≥ 4.0), and `reportlab` (≥ 4.0).

## Usage

### Check a PDF for WCAG 2.1 Level AA issues

```bash
python check_pdf.py <input.pdf> [options]
```

| Option | Description |
|--------|-------------|
| `--fix` / `-f` | Apply all automatic fixes before checking |
| `--output out.pdf` | Where to save the fixed PDF (default: `<name>_fixed.pdf`) |
| `--report-only` | Skip console summary; only generate report files |
| `--no-html` | Skip HTML report |
| `--no-txt` | Skip plain-text report |
| `--lang LANG` | BCP-47 language code to set when fixing (default: `en-US`) |
| `--title TITLE` | Document title to set when fixing (default: filename stem) |

**Examples:**

```bash
# Check only — saves <name>_accessibility_report.html and .txt
python check_pdf.py your_document.pdf

# Check and fix — saves fixed PDF, then reports on the fixed version
python check_pdf.py your_document.pdf --fix

# Fix with custom title and language
python check_pdf.py your_document.pdf --fix --title "Annual Report 2026" --lang en-US

# Save fixed PDF to a specific path
python check_pdf.py your_document.pdf --fix --output thesis_ua.pdf
```

### Fix a PDF only (LaTeX post-processing workflow)

For pdflatex + tagpdf users who only need the four PDF/UA structural fixes:

```bash
python fix_pdf.py <input.pdf> [options]
```

| Option | Description |
|--------|-------------|
| *(no option)* | Save fixed PDF as `<input>_fixed.pdf` |
| `--output out.pdf` | Save to a specific path |
| `--inplace` | Overwrite the input file directly |

**Typical LaTeX workflow:**

```bash
pdflatex thesis.tex
python fix_pdf.py your_document.pdf --inplace
```

The fixes are idempotent — running twice makes no further changes.

### Generate a test PDF

Creates a 6-page PDF with 10 deliberate WCAG 2.1 violations for testing:


Then run the checker on it:

## What is checked (WCAG 2.1 Level AA — 22 criteria)

### Perceivable
| Criterion | Name | Level |
|-----------|------|-------|
| 1.1.1 | Non-text Content — alt text on Figure elements | A |
| 1.3.1 | Info and Relationships — document tagging + table headers | A |
| 1.3.2 | Meaningful Sequence — reading order via structure tree | A |
| 1.4.3 | Contrast Minimum — text colour vs background (4.5:1) | AA |
| 1.4.4 | Resize Text — font Unicode encoding / text extractability | AA |
| 1.4.5 | Images of Text — scanned or image-only content | AA |
| 1.4.11 | Non-text Contrast — form field borders and UI components | AA |

### Operable
| Criterion | Name | Level |
|-----------|------|-------|
| 2.1.1 | Keyboard — tab order on pages with links/forms | A |
| 2.4.1 | Bypass Blocks — bookmarks for navigation | A |
| 2.4.2 | Page Titled — document title in metadata | A |
| 2.4.3 | Focus Order — form field tab order | A |
| 2.4.4 | Link Purpose — descriptive link text | A |
| 2.4.5 | Multiple Ways — bookmarks + TOC + page labels | AA |
| 2.4.6 | Headings and Labels — heading structure and levels | AA |

### Understandable
| Criterion | Name | Level |
|-----------|------|-------|
| 3.1.1 | Language of Page — `/Lang` in document catalog | A |
| 3.1.2 | Language of Parts — `/Lang` on multilingual passages | AA |
| 3.3.2 | Labels or Instructions — form field accessible labels | A |

### Robust
| Criterion | Name | Level |
|-----------|------|-------|
| 4.1.1 | Parsing — PDF/UA identifier + structure validity | A |
| 4.1.2 | Name, Role, Value — form field names and tooltips | A |

## What is automatically fixed

| Fix | What it does |
|-----|--------------|
| PDF/UA metadata | Adds `pdfuaid:part = 1` to XMP metadata |
| Document title | Sets `/Title` in DocInfo and XMP `dc:title` |
| Document language | Sets `/Lang` in the document catalog |
| TH scope | Adds direct `/Scope /Column` to every TH structure element |
| Untagged paths | Wraps untagged path sequences (booktabs rules) as `/Artifact` |
| Artifact content | Removes `/Artifact` wrappers that incorrectly enclose tagged content |
| Alt text | Adds `"Image — description needed"` placeholder `/Alt` to untagged Figure elements |

Issues that cannot be auto-fixed (require document re-authoring):
- Missing structure tree (untagged PDF)
- Low colour contrast
- Non-descriptive link text
- Missing bookmarks

## Output files

| File | Description |
|------|-------------|
| `<name>_accessibility_report.html` | Full visual dashboard with expandable issues, colour-coded status badges, and WCAG reference links |
| `<name>_accessibility_report.txt` | 80-column plain-text report for archiving or sharing |
| `<name>_fixed.pdf` | Auto-corrected PDF (only with `--fix`) |

---

## Notes

- **Non-destructive:** fixes only add/adjust accessibility markup. Visible content, fonts, and layout are never changed.
- **Tested on:** pdflatex + tagpdf (TeX Live 2025), 250+ page documents.
- **Not tested on:** XeLaTeX, LuaLaTeX, or non-LaTeX PDF generators.
- Contrast and images-of-text checks require manual verification — the tool flags them for review and explains what to look for.
